CYBER CITY LOCATION PACK (Replit Ready)

Contents:
- assets/locations/cyber_city/city_01.png ... city_06.png
- assets/locations/cyber_city/location_manifest.json
- assets/locations/cyber_city/location_sequence.js

Purpose:
This pack is prepared as a side-scrolling location sequence.
The segments are already ordered from left to right.

Segment order:
1. city_01.png
2. city_02.png
3. city_03.png
4. city_04.png
5. city_05.png
6. city_06.png

How to use:
- Load images in the order from location_sequence.js
- Place each image at its x position
- Move the camera from left to right while drawing the segments

Location size:
- Total width: 12288 px
- Total height: 1358 px

Files:
- location_manifest.json = ordered metadata for the level
- location_sequence.js = simple JS export for direct use in Replit
- location_helpers.js = optional helper functions
